# Swift Terminal Architecture Map

Swift support is a generated terminal language target for macOS first. It is
not a SwiftUI, AppKit, UIKit, native-window, web, or mobile backend.

## Target Scope

- Target spelling: `swift`.
- Runtime root: `swift/src/Uimd`.
- Generated example/app root: future `swift/examples` or user project
  directories generated by `./uimd generate ... --target swift`.
- Build/run model: SwiftPM (`swift build`, `swift run`, or built executable).
- Supported public platform for this slice: macOS terminal only.
- Linux and Windows Swift remain unadvertised until separate validation tasks
  prove toolchain, terminal, and runtime behavior.

## Source Ownership

- CLI, SDK target recognition, app scaffolding, and generator dispatch:
  `cpp/tools/uimd/main.cpp`.
- Swift generator: `cpp/tools/uimd/NativeSwiftGenerator.cpp` and
  `cpp/tools/uimd/NativeSwiftGenerator.hpp`.
- Python runtime reference: `src/uimd/runtime`.
- C++ parity implementation: `cpp/include/ui`, `cpp/src`, and
  `cpp/src/generated/GeneratedWindowRuntime.cpp`.
- C# structural reference for the newest language-port shape:
  `csharp/src/Uimd/Runtime` and `cpp/tools/uimd/NativeCSharpGenerator.cpp`.
- Swift runtime implementation: `swift/src/Uimd/Sources/Uimd`.

## Generator Parity Map

| Generator Surface | Existing Target | Swift Slice |
| --- | --- | --- |
| Target recognition | `main.cpp` target allow-list | `swift` added |
| `new --target` | Python/C++/C# templates | Swift app + SwiftPM manifest added |
| `generate --target` | Native Python/C++/C# generators | `NativeSwiftGenerator` added |
| Generated UI class | C# is closest structural port | Swift emits one `open class <Name>UI` per source |
| Public members | Python/C++/C# generated names | Swift properties use the same member names |
| Event hooks | Preferred override hooks | Swift emits `on<Element>Click/Change/Submit/...` |
| App stub | C++/C# generated launcher stubs | Swift `@main` launcher using `GeneratedWindowRuntime` |
| SDK runtime lookup | C# project reference properties | SwiftPM manifest chooses source checkout or installed `targets/swift` |

## Current Slice State

Implemented:

- `swift` target allow-list, `new`, `generate`, `sdk install-target`,
  installed SDK lookup, doctor target reporting, native parity smoke, and SDK
  release payload support.
- Swift generator for basic UI classes, layout metadata, event hook dispatch,
  app stubs, and SwiftPM manifests.
- Swift runtime package with generated-window API, event dispatch surface,
  close request, frame-buffer rendering, runtime layout resolution, basic
  controls, MCP server/tools, modal stack, and initial dialog/FileBrowser
  behavior.
- Reusable focus-background rendering that matches the C++ gap behavior:
  rendered child content is protected while empty padding and gap rows are
  tinted.
- Swift examples for `activity_feed`, `calculator`, `cells`,
  `contacts_manager`, `expense_tracker`, `formular`, `image_browser`,
  `image_gallery`, `markdown_viewer`, `special_elements`, `task_board`,
  `text_editor`, and `widget_gallery`.
- Swift runtime smoke tests.
- C++/Swift MCP compares for the full macOS Swift example matrix at
  `--compare-app-size 90x35`: `activity_feed`, `calculator`, `cells`,
  `contacts_manager`, `expense_tracker`, `formular`, `image_browser`,
  `image_gallery`, `markdown_viewer`, `special_elements`, `task_board`,
  `text_editor`, and `widget_gallery`.

Supported boundaries:

- Swift is advertised for macOS terminal apps only in this slice.
- SwiftUI, AppKit, UIKit, native Apple windows, Linux Swift, and Windows Swift
  are outside this target scope until separately requested and validated.
- Swift image coverage is terminal fallback/render-info parity; native Sixel
  encoding is not advertised as a Swift capability.
